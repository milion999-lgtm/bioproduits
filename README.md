# BioProduits

Site vitrine de démonstration autour des produits biologiques, avec un catalogue et un panier d'exemple.

## Pages

- Accueil : présentation de la boutique
- Produits : catalogue
- Panier : aperçu du panier de démonstration
- À propos et Contact

## Voir le site

[Ouvrir BioProduits](https://milion999-lgtm.github.io/bioproduits/)

## Lancer le site en local

Clonez le dépôt, puis ouvrez le fichier index.html dans un navigateur. Le site est statique; le panier sert de démonstration et ne traite pas de paiements ni de commandes réelles.
